# Provider sources and verification boundaries

Consulted 2026-11-16. Installed versions are recorded in planning/phase-0-evidence.json. Configuration may change; rerun native checks after upgrades.

- Antigravity hooks: https://antigravity.google/docs/hooks — project hooks, named event groups, camelCase input, tool gating and lifecycle output protocols. Actual hook cwd behavior required the payload-based launcher.
- Antigravity rules: https://antigravity.google/docs/rules — supported always_on activation frontmatter.
- Claude hooks: https://code.claude.com/docs/en/hooks — project settings, hook events, snake_case payload and permissionDecision output.
- Claude instructions: https://code.claude.com/docs/en/memory — @AGENTS.md import and duplicate instruction loading behavior.
- Codex configuration: https://learn.chatgpt.com/docs/config-file/config-reference — sandbox and approval configuration.
- Codex rules: https://learn.chatgpt.com/docs/agent-configuration/rules — execution policies and trusted project activation.

Native help, strict Codex startup parsing, prompt-input inspection, execpolicy check, Claude doctor, Antigravity plugin validation and bounded disposable sessions supply environment evidence. Documentation and parser success do not establish live activation or complete behavioral acceptance. No personal credentials, models, global settings or persistent trust decisions are included in generated adapters.

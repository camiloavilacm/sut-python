# Security and scope

This repository is an educational synthetic QA example, not a production authentication service. Do not deploy it with real user data or production credentials. Generate disposable local configuration using the documented tools and keep `.env`, operator authorization files, signing keys and deploy keys out of Git.

Report vulnerabilities through GitHub private vulnerability reporting when available. Otherwise contact the repository owner through GitHub without including a secret or exploitable credential in a public issue. Contributions and dependency updates require review and fresh appropriate verification. No long-term security-support commitment is made.
